# 威海佰源水产有限公司 · 企业官网

**线上地址：<https://zhang-min-ki.github.io/baiyuan-seafood/>**（GitHub Pages，已发布）
代码仓库：<https://github.com/zhang-min-ki/baiyuan-seafood>

由 PPT《威海佰源水产有限公司简介》整理而成的单页企业官网（深色深海金调）。
纯静态站点：无框架、无构建步骤，双击 `index.html` 即可在浏览器中打开。

## 更新线上内容

改完 `index.html` 或替换 `assets/` 里的图片后，在项目根目录执行：

```bash
GITHUB_TOKEN=你的令牌 bash "上线/github-pages发布.sh"
```

脚本会自动提交、推送、并轮询线上地址直到生效（本机 github.com 的 DNS 被污染，脚本用固定 IP 直连绕过，无需改 hosts）。

## 目录结构

```

├── index.html                  ← 主站（推荐使用，图片分离，加载更快）
├── 佰源水产官网-单文件版.html    ← 单文件版（图片已内嵌 base64，便于微信/邮件直接转发）

├── 部署包/index.html             ← 单文件版改名版，作为网站首页可直接上传
├── assets/                     ← 从 PPT 中提取并压缩后的图片（18 张，约 4 MB）
├── robots.txt
├── 上线/                        ← 国内上线用：采购与备案指南、nginx 配置、一键上传脚本
│   ├── 采购与备案指南.md
│   ├── nginx-baiyuan.conf
│   └── deploy.sh
├── 部署指南.md                  ← 各托管方案对比与步骤
└── README.md
```

## 待补充事项

1. `index.html` 中搜索 `待补充`，替换为真实联系电话、手机 / 微信、邮箱、详细地址。
2. 公司名称：PPT 中同时出现「威海佰源水产有限公司」与「威海佰源贸易有限公司」，
   本页面统一采用文件名中的「威海佰源水产有限公司」，如需更改请全局替换。
3. 产品页的英文拉丁学名为常见商品名标注，如需严谨可自行调整。

## 技术说明

- 字体：Google Fonts 的 Noto Serif SC / Noto Sans SC / Cormorant Garamond；
  离线环境下自动回退到系统宋体与雅黑，版式不受影响。
- 全站响应式：桌面三栏 → 平板两栏 → 手机单栏，含移动端抽屉菜单。
- 交互：滚动渐显、导航毛玻璃、产品分类筛选、阅读进度条、顶部回顶按钮。
